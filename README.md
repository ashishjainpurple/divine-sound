# 🎵 Divine Sound - DIVINE AI

An elegant, responsive web application for playing divine Hindu devotional sounds with an interactive player experience.

![Purple Jewels Divine Sound](https://img.shields.io/badge/divine--sound-v1.0-ffd36a?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)

## ✨ Features

### 🎼 Core Functionality
- **6 Divine Sounds**: Krishna Flute, Hanuman Chalisa, Shiva Mantra, Ganesh Aarti, Murugan Bhajan, Peacock Sound
- **Native HTML5 Audio Player**: Built-in controls with play/pause/stop buttons
- **URL Parameters**: Load specific sounds via `?id=sound-name` (e.g., `index.html?id=hanuman`)
- **Volume Control**: Adjustable volume slider with percentage display
- **Keyboard Shortcuts**: Press `SPACE` to play/pause

### 🎨 Enhanced UI
- Gradient background with golden accents
- Responsive design (mobile & desktop)
- Smooth animations and hover effects
- High-quality divine images
- Real-time status updates

### 🎧 Playlist Management
- Quick-select playlist grid
- Active sound highlighting
- Easy switching between sounds
- Emoji indicators for each deity

### 📱 NFC Support (Ready)
- NFC tag detection framework
- Future integration for tap-to-play functionality
- Graceful fallback for unsupported devices

## 🚀 Quick Start

### Option 1: Online (GitHub Pages)
1. Enable GitHub Pages in repository settings
2. Visit: `https://ashishjainpurple.github.io/divine-sound/`

### Option 2: Local
1. Clone the repository:
```bash
git clone https://github.com/ashishjainpurple/divine-sound.git
cd divine-sound
```

2. Open `index.html` in any modern web browser
